## Project Overview

This project focuses on designing, developing, and optimizing a high-performance web crawler for large-scale data extraction from the New Straits Times website, a Malaysian online news platform. The selected domain for this project is news article metadata from `https://www.nst.com.my/`.

The main objective is to collect at least 100,000 structured records, clean and process the dataset, apply high-performance computing techniques, and evaluate the performance improvement between baseline and optimized data processing pipelines.

## Project Objectives

- Build a web crawler to extract structured news article metadata from NST.
- Collect more than 100,000 structured article records.
- Store the extracted and cleaned data in CSV format.
- Clean and process the raw dataset.
- Apply high-performance optimization techniques.
- Compare baseline and optimized crawler and processing performance.
- Generate charts for performance evaluation and dataset analysis.
- Prepare a final project report with methodology, results, and discussion.

## Optimization Techniques

This project applied several optimization techniques:

### 1. Multithreaded Crawling

The optimized crawler uses `ThreadPoolExecutor` to fetch multiple article pages concurrently. This improves crawling speed compared to the baseline sequential crawler because web crawling is mostly I/O-bound.

### 2. Multiprocessing Data Cleaning

The optimized cleaning pipeline uses Python's `multiprocessing.Pool` to clean records across multiple CPU cores. This reduces processing time compared to single-process pandas cleaning.

### 3. Polars Lazy Execution

The analytical processing stage uses Polars lazy CSV scanning and expression-based transformations. This improves throughput and reduces processing overhead for aggregation tasks such as category summaries, monthly summaries, and top author analysis.

### 4. Progressive Data Writing

The crawler stores records progressively and exports the final raw and cleaned datasets in CSV format. This reduces the risk of losing collected data during long crawling runs and supports easier validation.

## Performance Evaluation

Crawler performance was compared between the baseline sequential crawler and the optimized threaded crawler.

| Method | Records | Total Time Seconds | Throughput Records/Second | CPU Usage % | Memory Usage MB |

| Baseline Sequential | 500 | 508.876 | 0.983 | 13.86 | 66.87 |
| Optimized Threaded | 500 | 165.303 | 3.025 | 30.01 | 69.95 |

| Method | Records | Total Time Seconds | Throughput Records/Second | CPU Usage % | Memory Usage MB |
| --- | ---: | ---: | ---: | ---: | ---: |
| Pandas Baseline | 102,265 | 7.510 | 13,617.90 | 92.0 | 466.40 |
| Multiprocessing | 102,265 | 6.231 | 16,413.57 | 75.0 | 528.96 |
| Polars Lazy Execution | 102,265 | 0.558 | 183,392.28 | 29.6 | 332.92 |

## Performance Improvement

The optimized threaded crawler achieved:

- Speedup: about 3.1x faster than the baseline sequential crawler.
- Throughput improvement: about 3.1x higher records per second.

The Polars analytical pipeline achieved:

- Much higher processing throughput than pandas baseline cleaning.
- Lower memory usage than the pandas baseline for analytical processing.
- Efficient output generation for summary CSV files.

These results show that combining parallel crawling, multiprocessing, and optimized analytical libraries significantly improves the efficiency of large-scale web data processing.

## How to Run

### 1. Run a Small Test Crawl

```powershell
python src\crawl_nst.py --mode basic --target-records 100 --max-sitemaps 1 --delay 0.5
```

### 2. Run the Final Optimized Crawl

```powershell
python src\crawl_nst.py --mode threaded --target-records 100000 --max-sitemaps 18 --workers 4 --delay 0.5
```

### 3. Clean the Dataset

Baseline cleaning:

```powershell
python src\clean_nst.py --mode basic
```

Optimized multiprocessing cleaning:

```powershell
python src\clean_nst.py --mode multiprocessing --workers 4
```

### 4. Run Polars Analysis

```powershell
python src\polars_nst.py
```

### 5. Generate Performance Charts

```powershell
python src\make_nst_charts.py
```

### 6. Validate Record Count

```powershell
python src\count_nst.py
```
