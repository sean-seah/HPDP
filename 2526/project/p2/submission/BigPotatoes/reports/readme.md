## 📝 Report Overview

The final report covers the following main sections:

1. **Introduction**  
   Provides the project background, objectives, and scope.

2. **Data Acquisition and Preprocessing**  
   Describes how Shopee Malaysia Google Play reviews were collected, cleaned, and prepared for sentiment analysis.

3. **Sentiment Model Development**  
   Explains the sentiment classification models, model training process, evaluation metrics, model comparison, and best model selection.

4. **Apache System Architecture**  
   Presents the real-time pipeline architecture using Apache Kafka, Apache Spark Structured Streaming, and Elasticsearch.

5. **Dashboard Analysis and Results**  
   Shows the batch and streaming sentiment analysis dashboards using Kibana and Power BI.

6. **Optimization and Comparison**  
   Compares batch and streaming processing performance based on processing time, throughput, CPU usage, memory usage, and system suitability.

7. **Conclusion and Future Work**  
   Summarizes the project outcomes and suggests possible improvements.
