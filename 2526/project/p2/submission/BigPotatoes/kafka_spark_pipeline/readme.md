# 📡 Kafka + Spark Streaming Pipeline

This folder contains the real-time sentiment analysis pipeline for the **Shopee Application Real-Time Sentiment Analysis using Apache Spark and Kafka** project.

The pipeline uses **Apache Kafka**, **Apache Spark Structured Streaming**, and **Elasticsearch** to stream cleaned Shopee review data, predict sentiment, and store the prediction results for validation and dashboard analysis.

---

## 📁 Folder Contents

| File | Description |
|---|---|
| `docker-compose.yml` | Starts the required Docker services: Zookeeper, Kafka, Elasticsearch, and Kibana. |
| `kafka_producer.py` | Reads `cleaned_data.csv` row by row and sends each review record to the Kafka topic. |
| `spark_streaming.py` | Consumes messages from Kafka, applies the trained sentiment model, saves results to CSV, and indexes records into Elasticsearch. |
| `test_model.py` | Tests whether the trained sentiment model can be loaded and used for sample sentiment predictions. |
| `streaming_prediction.csv` | Final streaming prediction output generated by Spark Structured Streaming. |
| `readme.md` | Documentation for this Kafka and Spark streaming pipeline folder. |

---

## ⚙️ Pipeline Overview

The real-time sentiment analysis pipeline follows this workflow:

```text
cleaned_data.csv
      ↓
Kafka Producer
      ↓
Kafka Topic: sentiment-topic
      ↓
Spark Structured Streaming
      ↓
Trained Sentiment Model
      ↓
streaming_prediction.csv + Elasticsearch
      ↓
Kibana / Power BI Dashboard
```

---

## 🧩 Main Components

### 1. Apache Kafka

Apache Kafka is used as the real-time messaging layer.

The Python Kafka producer reads cleaned Shopee review records from `cleaned_data.csv` and sends them into the Kafka topic:

```text
sentiment-topic
```

Each review is converted into JSON format before being sent to Kafka.

---

### 2. Apache Spark Structured Streaming

Apache Spark Structured Streaming is used as the real-time processing layer.

Spark consumes messages from the Kafka topic and processes the data in micro-batches. The trained sentiment classification model is applied to the `cleaned_text` field to classify each review into one of the following sentiment categories:

```text
Negative
Neutral
Positive
```

---

### 3. Elasticsearch

Elasticsearch is used as the storage layer for the streaming prediction output.

The prediction records are stored under the Elasticsearch index:

```text
sentiment_predictions
```

The indexed data can be validated using Kibana and used for dashboard analysis.

## 🚀 How to Run the Pipeline

### Step 1: Start Docker Services

Start Zookeeper, Kafka, Elasticsearch, and Kibana using Docker Compose:

```powershell
docker compose up -d
```

Check whether the containers are running:

```powershell
docker ps
```

Expected containers:

```text
hpdp-zookeeper
hpdp-kafka
hpdp-elasticsearch
hpdp-kibana
```

---

### Step 2: Create Kafka Topic

Create the Kafka topic used for streaming review data:

```powershell
docker exec -it hpdp-kafka kafka-topics --create --topic sentiment-topic --bootstrap-server hpdp-kafka:29092 --partitions 1 --replication-factor 1 --if-not-exists
```

Check the topic list:

```powershell
docker exec -it hpdp-kafka kafka-topics --list --bootstrap-server hpdp-kafka:29092
```

Expected output:

```text
sentiment-topic
```

> Note: Kafka may also show `__consumer_offsets`. This is an internal Kafka topic and can be ignored.

---

### Step 3: Test the Sentiment Model

Run the model test script:

```powershell
python test_model.py
```

This script checks whether the trained sentiment model can be loaded successfully and produces sample predictions from the cleaned review data.

---

### Step 4: Run Spark Structured Streaming

Set the Python environment for Spark:

```powershell
$env:PYSPARK_PYTHON="C:\HPDP_Project2\.venv\Scripts\python.exe"
$env:PYSPARK_DRIVER_PYTHON="C:\HPDP_Project2\.venv\Scripts\python.exe"
```

Start the Spark streaming job:

```powershell
spark-submit `
  --packages org.apache.spark:spark-sql-kafka-0-10_2.13:4.1.1 `
  --conf spark.network.timeout=600s `
  --conf spark.executor.heartbeatInterval=60s `
  spark_streaming.py
```

Expected output:

```text
Spark streaming started.
Listening to Kafka topic: sentiment-topic
Press Ctrl + C to stop.
```

Keep this terminal running.

---

### Step 5: Run Kafka Producer

Open another terminal and run:

```powershell
cd C:\HPDP_Project2\kafka_spark_pipeline
.\..\.venv\Scripts\activate

python kafka_producer.py --limit 0 --delay 0.001
```

`--limit 0` means all records from `cleaned_data.csv` will be sent to Kafka.

Expected output:

```text
Done. Total messages sent: 6395
```
