# Visual Analysis: Real-Time Sentiment Analysis of TNG eWallet Reviews

## 1. Dashboard Overview

The Kibana dashboard visualizes sentiment prediction results from Touch 'n Go eWallet Google Play reviews. The review data was processed through the Kafka and Spark Structured Streaming pipeline, indexed into Elasticsearch, and analyzed using Kibana visualizations. The dashboard provides an overview of predicted sentiment distribution, actual sentiment labels, prediction confidence, real-time streamed reviews, sentiment trends, and prediction outcome summary.

## 2. Predicted Sentiment Distribution

The predicted sentiment distribution chart shows the sentiment categories generated by the deployed Naive Bayes model. Based on the dashboard, positive sentiment represents approximately 68.56% of the processed reviews, while negative sentiment represents approximately 31.44%. This indicates that the model classified most Touch 'n Go eWallet reviews as positive, suggesting that many users expressed satisfaction with the application.

## 3. Actual Sentiment Labels

The actual sentiment labels chart shows the original sentiment categories derived from user rating scores. Positive sentiment accounts for approximately 68.66% of the dataset, negative sentiment represents approximately 27.46%, and neutral sentiment represents approximately 3.87%. The actual sentiment distribution is similar to the predicted sentiment distribution, indicating that the model output is generally consistent with the rating-based sentiment labels.

## 4. Prediction Confidence by Rating

The prediction confidence by rating chart shows the average model confidence for each review rating. Reviews with higher ratings, especially 4-star and 5-star reviews, generally show higher prediction confidence. This suggests that the sentiment model is more confident when classifying strongly positive reviews. Lower-rated reviews also show high confidence, but with slightly more variation due to the presence of mixed or unclear review text.

## 5. Real-Time Sentiment Stream

The real-time sentiment stream table displays individual review records processed by the streaming pipeline. Each record includes the processing timestamp, review text, predicted sentiment, prediction confidence, and rating. This table demonstrates that the Kafka producer, Spark Structured Streaming consumer, Elasticsearch index, and Kibana dashboard are connected successfully in an end-to-end real-time pipeline.

## 6. Sentiment Trend Over Time

The sentiment trend over time chart shows how positive, negative, and neutral reviews change across different months. Positive sentiment remains the dominant category throughout most of the observed period. Negative sentiment appears consistently across time, showing that users continue to report issues related to the application. Neutral sentiment remains relatively small compared with positive and negative sentiment.

## 7. Average Prediction Confidence

The average prediction confidence metric shows an overall confidence score of approximately 0.894. This indicates that the deployed Naive Bayes model generally produces sentiment predictions with high confidence. The metric provides a quick summary of model certainty across all processed reviews.

## 8. Prediction Outcome Summary

The prediction outcome summary compares actual sentiment labels with predicted sentiment labels. Most positive reviews are predicted as positive, and most negative reviews are predicted as negative. However, some neutral reviews are classified as either positive or negative, which is expected because neutral reviews often contain less clear sentiment expression. This table provides a simple validation view of how well the predicted sentiment aligns with the actual sentiment labels.

## 9. Word Cloud Analysis

The positive word cloud highlights common positive terms such as convenient, useful, transaction, transfer, fast, secure, friendly, reward, cashback, and parking. These words suggest that users appreciate the convenience, payment functionality, transfer features, rewards, and daily usability of the Touch 'n Go eWallet application.

The negative word cloud highlights common complaint terms such as transaction, reload, bad, notification, topup, balance, scan, verification, loading, support, error, and pin. These terms indicate that users mainly experience issues related to transaction processing, top-up and reload functions, verification, notifications, login or PIN usage, and application stability.

## 10. Key Findings

- Positive sentiment is the dominant sentiment category in both actual and predicted sentiment distributions.
- The predicted sentiment distribution is close to the actual sentiment distribution, suggesting that the deployed Naive Bayes model produces reasonable predictions.
- The average prediction confidence is high, with an overall confidence score of approximately 0.894.
- Higher-rated reviews generally have stronger prediction confidence, especially for 4-star and 5-star reviews.
- The real-time stream table confirms that the pipeline successfully processes and stores individual review records.
- Positive reviews mainly focus on convenience, transfers, rewards, secure payments, and daily usability.
- Negative reviews mainly focus on transaction failures, reload/top-up problems, verification issues, notifications, and application errors.

## 11. Conclusion

The dashboard successfully presents the sentiment analysis results stored in Elasticsearch. It allows users to monitor overall sentiment distribution, compare actual and predicted sentiment labels, observe sentiment trends over time, inspect real-time processed review records, and identify common positive and negative feedback topics. Overall, the Kibana dashboard provides useful visual insights into customer opinions toward the Touch 'n Go eWallet application and demonstrates the effectiveness of the Kafka, Spark Structured Streaming, Elasticsearch, and Kibana pipeline.
